## 1. DAO-Pattern: create-Methode

> Erläutert das Zusammenspiel von `DaoImp`, `PatientDao` und der Datenbanktabelle `patient`, wenn die im Interface `Dao` definierte Methode `void create(T t) throws SQLException` aufgerufen wird.

Wenn man create aufruft, ruft DaoImp diese Methode auf und fragt patientDao, wie das Sql Statement aussehen soll. PatientDao erstellt dann ein insert Statement mit den Daten aus dem Patient Objekt. Das  statement wird ausgeführt und speichert den Patienten in der Datenbank. PatientDao erbt von DaoImp und kann deswegen die create Methode nutzen, muss aber selber sagen, wie man die Daten in Sql umwandelt
